# Reader v220 · Source authority and clue knowledge checks

Production baseline: Reader v219 at merge 289b34728aa0da636e3f683254990d5d4bd6ae39.

## Portable source audit
The author HTML review package now groups live planning source records by explicit status: recorded approval, proposal, conflict, unresolved, written with unknown approval, and unclassified. It counts retired source records but excludes them from ordinary current source arrays and chapter lists. All detailed author review packages explicitly contain spoilers. Reader manuscript export is unchanged. A recorded approval classification is not an independent verification of literary truth.

## Clue knowledge requirements
Twists and Clues now offers a separately collapsed, proposal reviewed list of explicit facts required for a scene. Adding and retiring requirements is handled through the normal source proposal workflow, including book, branch, revision and linked fact/character snapshots. Author review and later verification remain required. The source audit compares only recorded approved knowledge acquisitions and reading order, distinguishing late acquisition, unread possession, missing acquisition and unknown timing without assuming what a character knows. Changes in linked fact or character sources invalidate previous review evidence.

No manuscript edits, automatic clue decisions, book content changes, database writes, cover changes or SCP/HQ changes were made. All features share Arabic and English code. Actual iPhone Safari acceptance, restore checks, and editorial reconciliation remain separate.
