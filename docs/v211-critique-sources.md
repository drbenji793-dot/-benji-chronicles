# Reader v211 | Evidence and source navigation

Starting point: v210 production commit e94de970ac0391f929b243837d43367ed429f9d0.

## Changes
1. Shared Review now groups saved structured findings by active severity priority, recorded strengths, deferred findings, and resolved or rejected history. All findings are retained. Source deep links open the containing group. Priority is not author approval, and manuscript changes are never automatically applied.
2. Authors can record evidence-supported strengths as a separate finding kind. The existing exact saved paragraph checks and duplicate protection continue to apply. No strengths are invented.
3. Synopsis now exposes a collapsed, read-only current source map for the selected view and plan or manuscript scope. It identifies book, branch and current planning revision, and displays each section origin, linked record revisions, changed or unavailable sources, and explicitly unresolved questions. Unlinked sources are never treated as verified. Publication is not inferred from a planning revision.
4. Twists & Clues cards display the saved chapter link where recorded, alongside current character, setup, and reveal labels. A rename follows the current stable record ID without rewriting historical prose.
5. Added targeted tests for ranked critique findings and source-backed strengths, source maps with missing and stale references, and stable dynamic labels for linked clue records.
