# Update stamps

Applies to Chronicles now. Universal rollout remains a separate project.

Every saved update carries a stable record ID, its revision, UTC saved time, writer, source revision and change note. The UI displays the date, time and explicit America/New_York timezone, including the correct EST or EDT offset label.

Site releases have their own version and release time. Record revisions are independent of the release. Exports preserve source revisions and saved times and add their own export time. Reopening, downloading or publishing a site does not restamp unchanged source records or confer approval.

Legacy information without a reliable timestamp displays the source snapshot revision and time as a fallback explicitly labelled source snapshot. Never invent an original save time.

Changes replace current information. Proposals remain separate from approvals. Superseded material links to its replacement and is excluded from ordinary current guidance. Historical copies remain available on demand.

Saving from a projected view first checks the source revision and merges into the complete document, then uses a guarded update. A concurrent change blocks the save. This preserves unloaded information and prevents stale updates.

Approval, implementation, verification and publication are separate states. Chapter prose requires its own review. Record the source revision checked before publication and any affected material still awaiting editorial work.
