# Reader v226 | Source gated questions and protected answer impact review

Production baseline: Reader v225, GitHub merge fd4049779a4e16b0abadfc45a564eddfe4a2f6f3.

## New question intake
A new manually created question must identify the decision type, explain why the choice is needed, and link a current event, character, saved chapter or structured critique finding. Authors can explicitly choose Current Story Brief as the source instead when a question is global to the book; a saved summary or Story Brief must exist. Retired or missing sources are rejected. Exact active question duplicates remain blocked by the previously approved rule. Existing saved legacy questions can still be edited without inventing or imposing new provenance. Approved decisions stay protected.

The new source scope and its saved Story Brief snapshot travel with portable question review packages, and later changes to that brief are flagged for recheck. A loaded chapter list is used for checking new linked chapter IDs, but the transient list itself is not copied into question records or history.

## Answer impact
Each active author question card now has one collapsed saved and proposed answer impact panel. It distinguishes earlier recorded answers from the latest saved answer, lists linked protected decisions without treating every shared event as a contradiction, shows current linked event/character/chapter availability, and retains the current Story Brief as an optional collapsed context. It never approves an answer or changes manuscript text. Protected prior answers remain effective until the linked revision is separately reviewed and applied.

The tests cover Arabic and English manual creation, an unsourced attempt rejected by the live editor, an explicitly sourced book wide question, duplicate and retired link rejection, protected decisions, old question compatibility, portable source scope preservation, before/after source comparisons, HTML escaping and the actual collapsed question card.

No novels, story records, author approvals, covers, SCP or HQ were edited. Physical iPhone Safari acceptance, manual author literary reconciliation and independent backup ZIP restoration remain open.
