# Ibn Elgabal Page Design

Ibn Elgabal is the master page template for Benji book and reading projects. Start future builds from that design and reuse its applicable structure on other pages. Every existing and new book in Arabic and English Chronicles uses the same chapter layout, including the header, reading area, spacing, navigation and editor controls.

The bottom editing and navigation row is followed by three compact grey disclosures, all closed by default: Notes, Chapter tools, Technical details. Keep the writing stamp, revision, save time, author, word count and release information in Technical details. Use the Notes and Chapter tools boxes for their corresponding features. Preserve each book’s own text, language direction, saved metadata and available actions.

Reuse the shared reader controls and technical footer rather than creating book-specific copies. Check both language editions, both storage paths and the mobile layout before releasing a reader change.
