# Reader v214 | Sourced before and after preview for connected changes

Base: Reader v213 production merge 846ce6748a27eb79e287a488265350e88234d945.

When an author prepares a connected change, the existing event and character record before/after review is supplemented by a current versus proposed Story Brief, linked protected question and recorded decision comparisons, and explicit separate manuscript follow-up links. Protected answers are shown preserved unless the candidate actually differs; a mismatch is visibly flagged for a separate decision review. Chapters are never automatically edited by this planning preview. Linked chapter IDs are described as references requiring independent manuscript source verification, not proof that a passage contains the planned fact. Events with no chapter reference are separately counted.

The new presentation uses escaping for all source values. Review remains a candidate until author approval and revision-aware application, as in the prior workflow. No story content, previously saved author choices, book records, covers, HQ or SCP records are modified by this release. The full Arabic and English regression suite includes pure immutable comparison tests, protected answer conflict tests, rendered escaped preview tests and existing staged/recovered UI tests.

Still open: source conflict reconciliation, actual iPhone Safari acceptance of preview/edit/download/share/reopen, external ZIP parity/restore verification and any final author decisions.
