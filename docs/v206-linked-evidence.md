# Version 206

Character and place edits or removals now mark events linked through stable IDs and their downstream connections for review. Existing literal character name matching remains available for older records.

Decision application and connected event verification snapshot the active characters and places referenced by affected events. Later content changes, retirement or removal reopen verification. Save stamps and unrelated record edits do not invalidate evidence. Earlier snapshots without linked record evidence require a fresh review; this conservative reopening is intentional.

Linked revisions of protected questions remain editable without treating their parent decision as an unrelated duplicate. They preserve the original single or compatible choice policy. The parent answer remains protected and a third unrelated duplicate is still rejected.

Regression coverage tests manual record updates and removal, transitive event impact, verified application reopening, review reopening, legacy evidence, metadata stability, unrelated changes, linked revision edits and choice policy preservation. No manuscript or production planning records are changed by this release.
