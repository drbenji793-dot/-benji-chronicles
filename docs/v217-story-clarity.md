# Reader v217 | Story clarity and source-linked review

Baseline: verified public Reader v216 at GitHub merge 032b29bd095838024da87a072aa1ffa8138f8ab6.

## Shared Story structure
The existing saved concise summary remains the Story opening. A new collapsed Story structure and sources panel categorizes recorded material and its destination: story essence, full synopsis, chapter sequence, character roles, unresolved decisions, event mechanics, research and revision history. It shows protagonist, desire, loss, opposition and stakes only when expressly recorded in the current data. Empty slots are labeled unrecorded rather than generating unsupported narrative. Character cards remain authoritative for biographies; Story displays small linked roles and current revisions.

## Source reconciliation
Synopses scan recorded character aliases for source identity review even when the section has no explicit character source link. Unicode boundary matching avoids partial matches in longer Arabic and English words. An alias is never declared obsolete automatically, and the original text is not rewritten. Linked critique findings are attached to synopsis sections only through explicit stable source IDs. Their original chapter revision and paragraph evidence remain visible as unresolved review items rather than accepted repairs.

## Questions
The question source inspector now shows the current saved chapter linked to the question, its exact stable ID and saved/current revisions, and any stale, missing or retired chapter source. A current chapter link is offered when available. This never authorizes automatic manuscript editing.

## Verification and protection
Changes apply to reusable shared software in both editions and do not alter existing books, drafts, chapters, covers, author decisions or database records. Four new regression programs test source inventory, link resolution, alias review, explicit critique evidence, revision drift and immutable content. The complete release suite and edition builds must pass before publication. Browser geometry and iPhone Safari acceptance remain separate. External backups and recovery parity are also not verified.
