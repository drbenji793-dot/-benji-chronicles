# Reader v229

Twists and Clues record details now includes Find related prose. The author selects a saved chapter and exact wording or a name. The tool fetches that chapter using the existing edition scoped source path and rejects a changed chapter revision. Results retain chapter revision and paragraph numbers, safely render the saved text and identify matches as editorial review candidates only. Planning changes or a switched branch during loading reject results. Failure clears previous results and allows retry.

This completes the reusable occurrence review alongside existing guarded structured fact proposals. It does not infer semantic contradictions, search wording variants, approve facts, persist editorial findings or change manuscript text. Only the selected saved chapter is checked. Actual iPhone acceptance and literary reconciliation remain separate.

Arabic and English rendered handler tests cover matching, word boundaries, escaped markup, stale chapter, switched branch, retries and unchanged planning. Existing approval tests cover separate proposed facts, protected decisions, explicit author approval, stale source blocking and reopening.
