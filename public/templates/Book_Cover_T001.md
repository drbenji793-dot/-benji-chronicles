# Book Cover T001

Every new book uses a large illustrated portrait cover matching the Lost Files cover: 2:3 proportions, full available width up to 440px, centered alignment, 4px corner radius, matching shadow, gold title and credit overlays, and an ornamental gold border in the artwork. The whole cover opens its book. Do not use a small horizontal text card.

Create dedicated artwork grounded in the book’s text, register it in bookArtwork in src/new-books.js, and use the same cover on the shelf and book overview. The generic collection artwork is only a temporary fallback while a book’s own illustration is prepared.

Preserve chapters, rules, history, writer identity, and approval controls. Test mobile overflow and verify that the new cover has the same width and height as Lost Files at the same viewport.

Ibn Al Jabal artwork: public/artwork/ibn-al-jabal-cover-v1.webp. Created using built-in image generation: Mamluk Cairo copyist workshop, manuscripts, ink, closed wooden chest and distant citadel; deep green and antique gold, no generated lettering. The Arabic title and credits remain readable HTML.
