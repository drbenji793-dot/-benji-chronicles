What opening it reveals

  1. Content or chapter version and last successful saved modification.
  2. Author or editor, with writing method when recorded: manual, AI assisted, adaptation or translation.
  3. Applied style and version, workflow status, protection state and concise last change.
  4. Website version, release time and source commit in a separate release group.
  5. Copy and Undo only when connected to real actions. Never render a decorative control that does nothing.

Timestamp contract

  1. Store an unambiguous ISO timestamp with offset or Z. Display date, seconds, timezone abbreviation and America/New_York when that is the selected timezone.
  2. Opening a rectangle, reloading a page, changing theme or downloading a copy must not alter the saved content time.
  3. A successful content save creates a content revision. A website deployment creates a release record. They are not interchangeable.
  4. Missing values say Not recorded. Do not substitute the current time, zero, null text or a guessed author.
